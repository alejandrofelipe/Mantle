# Migration gotchas: 1.21.4 → 1.21.5 (roadmap M3)

Companion to [`1.21.1-to-1.21.4.md`](1.21.1-to-1.21.4.md). Target: **MC 1.21.5 / NeoForge 21.5.101**, Parchment
`1.21.5 / 2025.06.15`, JEI `21.4.0.27`. Plan: `tinkers/docs/superpowers/plans/2026-10-24-m3-1.21.5-port.md`.

## Target choice & toolchain

- Compat was complete for 1.21.5 (JEI, Crafting Tweaks/Balm, Parchment). IE still 1.21.1-only (excluded); JSON Things
  has 1.21.4 and 1.21.6 builds but none for 1.21.5 (excluded; re-add at M4).
- Toolchain unchanged: the official `MDK-1.21.5-NeoGradle` uses NeoGradle **7.1.39** + Gradle **9.2.1**, Java 21.
- `dependencies --configuration runtimeClasspath` only resolves; the MC decompile (`build/neoForm/neoFormJoined1.21.5-*/
  steps/transformSource/transformed/`) is produced by the first `compileJava`. That tree is the ground truth for
  signatures — the primer is occasionally imprecise.

## Blocks & block entities

- `Block#onRemove` is gone. `LevelChunk.setBlockState` now runs, **only when the block changes** (`!old.is(newBlock)`):
  `BlockEntity#preRemoveSideEffects(pos, oldState)` (server, unless flag 256) → `removeBlockEntity` →
  `BlockState#affectNeighborsAfterRemoval`. The BE is **already gone** in `affectNeighborsAfterRemoval`, so a straight
  rename of drop logic silently stops dropping items.
- `BlockEntity#preRemoveSideEffects`'s default now calls `Containers.dropContents` for any `Container` — manual drops
  + `super` = double drops. Mantle routes `MantleBlockEntity#preRemoveSideEffects` → `InventoryBlock#preRemoveSideEffects`
  (keeps the `dropInventoryItems` hooks) instead of the vanilla default.
- Inside that hook the level already holds the new state: `level.getCapability(cap, pos, ctx)` sees the new block — use
  the `(pos, state, blockEntity, ctx)` overload with the old state + BE.
- Comparator updates moved to `affectNeighborsAfterRemoval` (`Containers.updateNeighboursAfterDestroy`).
- `Block#appendHoverText` removed → tooltips go on the `BlockItem` (Mantle `RetexturedBlockItem`).
- `entityInside` takes an `InsideBlockEffectApplier`; queue effects (e.g. `runAfter(LAVA_IGNITE, …)`) like vanilla fire.
- `Level#updateNeighborsAt(pos, block)` needs an `Orientation` (`ExperimentalRedstoneUtils.initialOrientation`).
- `BlockEntityRenderer#render` gains a camera `Vec3`.

## NBT

- Typed getters return `Optional<T>`; use `get*Or(key, default)`, `getCompoundOrEmpty`, `getListOrEmpty(key)`
  (`getList` lost its element-type argument). `contains(key)` stays, `contains(key, type)` is gone — for "is numeric"
  use `get(key) instanceof NumericTag n` → `n.intValue()`. `ListTag#getCompoundOrEmpty(i)` keeps the old semantics.
- `ItemStack.parseOptional`/`saveOptional` removed → `ItemStack.parse(...).orElse(EMPTY)` (special-case an empty tag or
  it logs an error) / codecs. `TagParser.parseTag` → `parseCompoundFully`. `NbtUtils` pos/UUID helpers gone → `tag.store`
  / `read` with `BlockPos.CODEC` / `UUIDUtil.CODEC`.
- NeoForge `FluidStack.parse/parseOptional/save*` and `FluidTank.readFromNBT/writeToNBT` survive.

## Items

- `ArmorItem` (and `SwordItem`/`DiggerItem`/…) removed → plain `Item`; `Item.Properties#humanoidArmor(material, type)`
  applies durability, attributes, enchantable, equippable and repairable like the old `ArmorItem` constructor.
- `Item#appendHoverText(stack, ctx, TooltipDisplay, Consumer<Component>, flag)`; Mantle added `Consumer` overloads of
  its tooltip helpers (the `List` versions delegate).
- `CONSUMABLE` has no automatic tooltip, so Mantle's effect tooltips stay.
- `Inventory.items`/`offhand` → `getNonEquipmentItems()` / `player.getOffhandItem()`; `selected` is private.
- `FluidStack#getDisplayName` → `getHoverName`.

## Gametests (Phase 2B)

- `@GameTest`, NeoForge `@GameTestHolder` and `@PrefixGameTestTemplate` are removed. A test is a
  `Registries.TEST_FUNCTION` entry (static registry of `Consumer<GameTestHelper>`) plus a `TEST_INSTANCE`
  (`FunctionGameTestInstance(functionKey, TestData)`) registered on NeoForge's `RegisterGameTestsEvent` (fires on every
  registry load when gametests are enabled: gametest server, dev client, or `-Dneoforge.enableGameTest=true`).
- `TestData(environment, structure, maxTicks, setupTicks, required)`: `timeoutTicks` → `maxTicks`; the template is a
  full `ResourceLocation` (the old `@PrefixGameTestTemplate(false)` → just use `tconstruct:gametest/...`).
  Environments live in `Registries.TEST_ENVIRONMENT` (vanilla `minecraft:default` = empty `AllOf`).
- `GameTestHelper.fail/assertTrue/assertFalse/assertValueEqual` take a `Component`; `GameTestAssertException(Component,
  tick)`; `helper.assertionException(...)` builds one.
- The gametest server runs all registered instances (no namespace property any more); `--tests <selector>` filters.
  Tinkers keeps old call sites with a tiny `@TinkerGameTest(template, timeoutTicks)` annotation + a reflective registrar
  (unwrap `InvocationTargetException` so assertion failures report as test failures).

## Tinkers-side gotchas (Phase 2A)

- **NBT:** no typed `contains(k, type)` / `getList(k, type)` / `Tag.TAG_ANY_NUMERIC` → Tinkers `TagUtil.contains/getList/
  isListOf/isType` (`getList` returns the live list only if every element matches, else a fresh empty one);
  `ListTag.getElementType` gone; `NumericTag.getAsX` → `xValue()`; `Tag.getAsString` → `asString().orElse("")`;
  `getAllKeys` → `keySet()` (a **live view**); `getTagType` → `get(k).getId()`; `NbtUtils.writeBlockPos` → same int
  array via `TagUtil.writePos`, read via `BlockPos.CODEC`. Public modifier NBT API (`IModDataView`, `ModDataNBT`,
  `RestrictedCompoundTag`) kept stable with `get*Or` defaults (decision D1).
- **Shields:** vanilla now decides shield disabling from the attacker's `WEAPON.disableBlockingForSeconds`, and
  **blocking itself requires a `BLOCKS_ATTACKS` component** — without it Tinkers' shields and Parrying block nothing.
  `ToolStack.updateComponents(stack)` writes/removes `WEAPON(0, 5s)` (shield disable) and `BLOCKS_ATTACKS` (vanilla
  shield values) from tool actions, on rebuild/create/update/load. `Player#disableShield` → `BlocksAttacks#disable`;
  `ItemAbilities.SHIELD_BLOCK` removed (Tinkers `TinkerToolActions.SHIELD_BLOCK`, same id); `LivingShieldBlockEvent` is
  no longer cancelable → `setBlocked(false)`.
- **Enchanting:** `isBookEnchantable` → `supportsEnchantment` (NeoForge now routes anvil books through it too).
- **Inventory tick:** `ItemStack.inventoryTick(ServerLevel, entity, @Nullable EquipmentSlot)` — vanilla passes
  `MAINHAND` only for the selected slot and `null` for the rest of the inventory; server only; mobs now tick equipment.
- `ItemStack.onCraftedBy(level, player, n)` → `(player, n)`; `FluidStack.isFluidEqual` → `isSameFluidSameComponents`;
  `AbstractArrow.getBaseDamage` removed (Tinkers needs an AT on `baseDamage`); `Level.blockUpdated` →
  `updateNeighborsAt(pos, block, null)`; `CommonHooks.onLivingFall` returns the event; `Mob.armorDropChances` →
  `setDropChance`/`getDropChances().byEquipment`; `isInWaterOrBubble` → `isInWater`; `Sheep` → `animal.sheep`;
  `SoundEvents.ITEM_BREAK/SHIELD_BLOCK/SHIELD_BREAK` are holders; `TriState` → `net.minecraft.util`.
- Blocks: `LeavesBlock(float, props)` with abstract `codec()`/`spawnFallingLeavesParticle`; `SaplingBlock.SHAPE` /
  `MangrovePropaguleBlock.SHAPE_PER_AGE` private; `DyedItemColor` lost its tooltip flag (use `TOOLTIP_DISPLAY`).
- Data: `ItemSubPredicate` → `DataComponentPredicate` (`matches(DataComponentGetter)`), `ItemPredicate.Builder
  .withSubPredicate/hasComponents` → `withComponents(DataComponentMatchers…)`; `DisplayInfo` background is
  `Optional<ClientAsset>` with an id without `textures/` and `.png`; `PotionContents` tooltips are component-driven
  (scale via `POTION_DURATION_SCALE`); `TrimMaterial(MaterialAssetGroup, description)`, ingredients carry
  `PROVIDES_TRIM_MATERIAL`, `TrimPattern` lost `templateItem` (`getFromTemplate` removed).
- Worldgen: `SpawnerData` lost its weight → `Weighted`/`WeightedList`, `AddSpawnsBiomeModifier.singleSpawn`;
  `WeightedList.of(Weighted)` resolves to the wrong overload — use the builder.
- Tooling trap: PowerShell flattens `@( @(a,b) )` into `@(a,b)` — it corrupted a file in a scripted edit.

## Misc

- `ResourceLocation.Serializer` removed → Mantle's `ResourceLocationSerializer.resourceLocation("minecraft")`.
- `ClickEvent`/`HoverEvent` are sealed interfaces of records (`new ClickEvent.OpenFile(path)`).

## Render pipeline

- `RegisterShadersEvent`/`ShaderProgram`/`CoreShaders` → `RenderPipeline.builder(snippet…)` registered in
  `RegisterRenderPipelinesEvent`. `withVertexShader`/`withFragmentShader` ids map to `shaders/<path>.vsh/.fsh`; the core
  shader JSONs are gone. Uniforms must be declared on the pipeline, and only `GlProgram.BUILT_IN_UNIFORMS` get values.
- **`mat3` uniforms are unsupported** — GL leaves them at zero without an error (Mantle's fluid fog used `IViewRotMat`).
- `RenderType.create(name, bufferSize, affectsCrumbling, sortOnUpload, pipeline, compositeState)`: shader, transparency,
  cull, depth and write-mask shards moved into the pipeline (`BlendFunction.TRANSLUCENT` ≙ the old
  `TRANSLUCENT_TRANSPARENCY`; builder defaults = cull, LEQUAL, color+depth write). Extending `RenderType` now means
  implementing `draw`/`format`/… — make render-type holders plain utility classes.
- `BufferUploader` removed → draw through `MultiBufferSource` + `RenderType`. `ScreenEffectRenderer.renderFluid` and
  `IClientFluidTypeExtensions.renderOverlay` take a `MultiBufferSource`.
- `RenderSystem.enableBlend/blendFuncSeparate/defaultBlendFunc/clear/bindTexture` removed; `GlStateManager` moved to
  `com.mojang.blaze3d.opengl`; `setShaderTexture` takes a `GpuTexture`; `setShaderColor` stays.
- `TextureTarget` lost `bindWrite`/`unbindWrite`; `NativeImage.downloadTexture`/`flipY` removed. Pixel readback:
  `copyTextureToBuffer` + `readBuffer` (synchronous map waits for the copy). `Screenshot.takeScreenshot(target, consumer)`
  is **async** (image arrives a frame later) and forces alpha opaque — Mantle's uitest uses its own synchronous
  `RenderTargetCapture` so the PNG exists before the harness exits.
- GUI `RenderType`s always draw to the main target: offscreen export (Mantle `BookCommand`) resizes the main target,
  clears it transparent, captures with alpha, then restores the window size.

## Models

- **`BakedModel` is gone.** Unbaked models no longer bake: `UnbakedModel` exposes only `parent()` (a
  `ResourceLocation`), `textureSlots()` and `geometry()`; parents are reachable only through `ResolvedModel`;
  `geometry() == null` means "inherit the parent's". `UnbakedGeometry.bake(...)` → `QuadCollection`; NeoForge loaders
  extend `AbstractUnbakedModel(StandardModelParameters)` and return an `ExtendedUnbakedGeometry`.
- A geometry bake receives the **top** `ResolvedModel` as its `debugName` — walk the chain to find your own node.
- **A model-JSON loader can only produce static geometry.** A blockstate variant `{"model": …}` always becomes
  `SingleVariant` → `SimpleModelWrapper` (fixed quads). Dynamic models must be **block-state types**
  (`CustomUnbakedBlockStateModel` → `DynamicBlockStateModel`, registered in `RegisterBlockStateModels`) referenced as
  `{"type": "mantle:connected", "model": "…", "y": 90}` (also inside multipart `apply`). Model JSONs can stay as they are.
- `DynamicBlockStateModel#collectParts(level, pos, state, random, parts)` gets the world (connected textures read
  neighbors directly); return a stable `createGeometryKey` for chunk-mesh caching; `particleIcon(level, pos, state)`.
- `ModelData` survives in the common package `net.neoforged.neoforge.model.data`; read it in `collectParts` via
  `level.getModelData(pos)`. Fake levels (book previews) must override `getModelData(pos)`.
- A `ModelBaker` exists only during bake: capture elements + resolved texture slots then (Mantle `ElementModelData`)
  and re-bake at runtime with `FaceBakery` + `Material::sprite` (retextured tables, cached per texture).
- Vanilla `BlockModel`/`SimpleUnbakedGeometry` are records, so parent elements are readable again (restores colored
  models without own elements, and retextured tables that inherit elements). `TextureSlots.Reference`/`Value` are
  package-private, but `Data.values().keySet()` is public — Mantle follows `#refs` with a probe-resolve trick
  (`ModelHelper.findReferences`), which also fixed connected clear glass not connecting through `block/cube_all`.
- Particle and AO are resolved by the caller from texture slots → item-like loaders add `particle → #layer0` themselves.
- `ModelState#getRotation` → `transformation()`; `isUvLocked` and NeoForge `SimpleModelState` are gone — UV lock is
  per-face `faceTransformation` (Mantle `ModelHelper.withUvLock`/`isUvLocked`). Custom `ModelState`s must forward
  `mayApplyArbitraryRotation()` or `FaceBakery` skips the winding recalculation.
- `BlockElement`/`BlockElementFace` are records; `BlockFaceUV` → nullable `UVs` + `Quadrant` rotation. Copy faces with a
  **new** `MutableObject` — the `BlockElement` constructor rebinds `face.parent()`.
- Item side: `BlockModelWrapper.Unbaked` takes a single render type → multiple render types need multiple layers
  (Mantle `ModelHelper.addItemLayer(renderState, stack, ctx, quads, ModelRenderProperties, renderType, extents)`);
  `ModelRenderProperties.fromResolvedModel(baker, resolved, slots)`.
- Datagen: NeoForge's `CustomBlockStateModelBuilder.Simple` **drops x/y rotations** — Mantle's
  `VariantBlockStateModelBuilder.connected(id)/.retextured(id)` applies `VariantMutator`s.
- Block rendering takes `List<BlockModelPart>`: `model.collectParts(level, pos, state, random)` then
  `tesselateBlock(parts, …)` (the deprecated `collectParts(random)` loses level context).
- `Level`: `playSeededSound`/`levelEvent` take an `Entity`; `setMapData`/`getFreeMapId` removed.
