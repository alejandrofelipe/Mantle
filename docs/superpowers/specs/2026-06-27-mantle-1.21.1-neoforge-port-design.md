# Mantle → 1.21.1 / NeoForge 21.1.234 Port — Design

**Date:** 2026-06-27
**Repo:** `alejandrofelipe/Mantle` (fork of `SlimeKnights/Mantle`)
**Branch:** `1.21.1` (created from `1.20`)
**Status:** Approved design — ready for implementation planning

---

## Context

This is the **first sub-project** of a larger effort to bring the `alejandrofelipe/TinkersConstruct`
fork to **Minecraft 1.21.1 on NeoForge 21.1.234**.

Research established the real starting point:

| Repo | Latest branch | Modloader |
|------|---------------|-----------|
| `SlimeKnights/TinkersConstruct` | `1.20.1` | Forge 47 |
| `SlimeKnights/Mantle` | `1.20` | Forge 47 |
| `alejandrofelipe/TinkersConstruct` | `1.20.1` | Forge |
| `alejandrofelipe/Mantle` | `1.20` | Forge |

**No official 1.21.1/NeoForge port exists.** Per the [SlimeKnights FAQ](https://slimeknights.github.io/faq/)
and [issue #5539](https://github.com/SlimeKnights/TinkersConstruct/issues/5539), the official team plans
to port **Mantle (and Metalborn) to 1.21.1/NeoForge first**, then Tinkers' Construct — no ETA. A community
reference attempt exists at [LopyLuna/Tinkers21Port](https://github.com/LopyLuna/Tinkers21Port) (single
branch, early stage).

**Tinkers' Construct cannot compile without a 1.21.1 Mantle.** Therefore Mantle is the mandatory first
step and the subject of this spec. Tinkers' Construct is a separate, later sub-project.

### Why this is large

Porting from **1.20.1+Forge → 1.21.1+NeoForge** combines two heavy changes:

1. **A 4-version Minecraft jump (1.20.1 → 1.21.1).** The critical break is **1.20.5 Data Components**,
   which replaced item NBT. (Mantle itself stores almost no item NBT — that pain is mostly Tinkers' — but
   fluids and codecs are affected.)
2. **A modloader change (Forge → NeoForge).** Registration, capabilities, networking, config, and the
   event bus all have different APIs.

Mantle is ~**593 Java files / ~50k LOC**. Coupling signals from the `1.20` branch:

- **170 files** import `net.minecraftforge.*` (the bulk is mechanical 1:1 rewrites).
- Networking is centralized (`NetworkWrapper` / `MantleNetwork` + ~10 packets behind `ISimplePacket`).
- **FluidStack:** 21 files. **Capabilities:** 18 files. **RecipeSerializer:** 17 files.
- Item NBT (`getOrCreateTag`/`CompoundTag`): ~0 — Data Component migration is light here.

## Decisions (locked)

- **First milestone:** Mantle only (Tinkers is a later cycle).
- **Definition of done:** Mantle **compiles AND loads in-game** — `gradlew build` green, `runData`
  regenerates assets, `runClient` launches with the mod registered and a passing smoke test.
- **Strategy:** compiler-driven, reference-assisted, executed in incremental verifiable stages.
- **Build system:** **NeoGradle** (7.x).
- **Targets:** Minecraft **1.21.1**, NeoForge **21.1.234** (fallback 21.1.233), Parchment **2024.11.17**,
  JEI **19.x** (1.21.1 line), **JDK 21**.
- **Execution is staged**; this document defines the destination and the order, not a per-line diff.

## Section 1 — Setup: repo, branch, versions

- Work lives on branch `1.21.1` (already created from `1.20`).
- `gradle.properties` becomes:
  - `minecraft_version=1.21.1`, `minecraft_range=[1.21.1,1.21.2)`
  - `neoforge_version=21.1.234` (fallback `21.1.233`)
  - `parchment_version=2024.11.17`, `parchment_minecraft=1.21.1`
  - `jei_version=19.21.0.247` (real published 1.21.1/NeoForge build on the BlameJared maven; reconfirm at execution time)
  - `mod_version` bumped to the next minor (e.g. `1.12`) to signal the version break
- JDK toolchain raised to **21** (was 17).
- This spec is committed on branch `1.21.1` under `docs/superpowers/specs/`.

## Section 2 — Build migration (NeoGradle)

- **`build.gradle`:** drop `net.minecraftforge.gradle` and `org.parchmentmc.librarian.forgegradle`;
  add `net.neoforged.gradle.userdev` (NeoGradle 7.x). Keep `io.freefair.lombok` and `maven-publish`.
- **`settings.gradle`:** replace Forge `pluginManagement`/repos with the NeoForged maven
  (`https://maven.neoforged.net/releases`).
- **Repositories:** add NeoForged; keep BlameJared (JEI) and Prog's maven (SlimeKnights libs); remove
  Forge-only repos.
- **Runs:** configure `client`, `server`, `data` (datagen), and `gameTestServer` if present, NeoGradle-style.
- **Mod metadata:** migrate `META-INF/mods.toml` → `META-INF/neoforge.mods.toml` (NeoForge format) with
  `loaderVersion`, `dependencies` on `neoforge`/`minecraft` in the correct ranges, and JEI as an **optional**
  dependency.
- **Done when:** `gradlew` dependency refresh + NeoGradle setup run cleanly and the IDE indexes decompiled
  MC 1.21.1 — **before** editing any `.java`.

## Section 3 — Staged porting order (compiler-driven)

| Stage | Focus | Done when |
|-------|-------|-----------|
| **0** | Build & toolchain (Sections 1–2) | Gradle syncs, decompiled MC 1.21.1 indexed |
| **1** | Global mechanical sweeps: `net.minecraftforge.*`→`net.neoforged.*` imports (1:1); `new ResourceLocation(...)`→`ResourceLocation.fromNamespaceAndPath`/`parse`; `MinecraftForge.EVENT_BUS`→`NeoForge.EVENT_BUS`; event-bus annotations | Import-level errors collapse; remaining errors are real API changes |
| **2** | Foundation: entrypoint `Mantle.java`, `registration/*`, `data/loadable`+`gson` (codecs), `config` | Base packages compile |
| **3** | Networking: `network/*` → payloads + `StreamCodec` | `network` compiles |
| **4** | Content: `fluid/*`, capabilities, `item`/`block`/`block/entity`, `inventory` | Compiles |
| **5** | Data: `recipe/*` (serializers/ingredients/conditions), `loot/*`, `command/*` | Compiles |
| **6** | Client: `client/model`, `render`, `screen`, `book`, fluid texture/tooltip | Client compiles |
| **7** | Integration: `plugin/jei`, `datagen` | `gradlew build` **green** |
| **8** | Runtime: `runData` regenerates assets, `runClient` launches, mod loads, smoke test | Definition of done met |

## Section 4 — Migration map for the hard areas (Forge 1.20.1 → NeoForge 1.21.1)

- **Registration:** `RegistryObject<T>` → `DeferredHolder<T,U>`; `ForgeRegistries.*` →
  `BuiltInRegistries`/`NeoForgeRegistries`; registration via `RegisterEvent`. Mantle's own wrappers
  (`registration/deferred`, `adapter`, `object`) are rewritten over the new API.
- **Entry / event bus:** `@Mod` takes `IEventBus`/`ModContainer` in the constructor;
  `net.minecraftforge.fml`→`net.neoforged.fml`, `eventbus`→`net.neoforged.bus`; `@EventBusSubscriber`
  re-packaged.
- **Networking:** `SimpleChannel`/`registerMessage` → `CustomPacketPayload` (record + `Type<>` +
  `StreamCodec<RegistryFriendlyByteBuf,T>`), registered in `RegisterPayloadHandlersEvent`
  (`playToClient`/`playToServer`/`playBidirectional`). Re-implement Mantle's `NetworkWrapper`/`ISimplePacket`
  over this.
- **Fluids:** `FluidStack` changes package and now wraps `Holder<Fluid>` + `DataComponentPatch`
  (NBT → components); `isFluidEqual`→`isSameFluidSameComponents`; `IFluidHandler` via the new capability API.
- **Capabilities:** `Capability<T>`+`@CapabilityInject`+`LazyOptional` → `BlockCapability`/`ItemCapability`/
  `EntityCapability` registered in `RegisterCapabilitiesEvent`, queried via `level.getCapability(cap, pos, …)`,
  returning `@Nullable` (no `LazyOptional`).
- **Recipes:** `RecipeSerializer.fromJson/toNetwork` → `MapCodec<T>` + `StreamCodec`; custom ingredients via
  `ICustomIngredient` (NeoForge); `CraftingHelper`/conditions → `neoforge:conditions` codec system.
- **Loot:** `LootItemFunctionType`/`ConditionType` now take a `MapCodec`; registered via `DeferredRegister`.
- **Client:** Forge model loaders → `net.neoforged.neoforge.client.model`; registration via events
  (`RegisterMenuScreensEvent`, `EntityRenderersEvent`, `RegisterColorHandlersEvent`, `ModelEvent`).
  `client/book` (HTML export) is the heaviest area and a deferral candidate.
- **Config:** `ForgeConfigSpec` → `ModConfigSpec`; register via `modContainer.registerConfig(...)`.
- **Datagen:** `GatherDataEvent` stays, but providers now take `CompletableFuture<HolderLookup.Provider>`.

## Section 5 — Verification & runtime

- **Per package cluster:** at each stage gate, `gradlew compileJava` (and `compileTestJava` if present)
  must report **zero** errors before advancing. Deprecation warnings are triaged, not ignored.
- **Full build:** `gradlew build` green (Stage 7).
- **Datagen:** `gradlew runData` runs to completion and regenerates Mantle's assets/data JSON without
  exception. Generated-JSON diffs are reviewed (format changes expected; content loss is not).
- **In-game smoke test (Stage 8 — the definition of done):**
  1. `runClient` reaches the main menu without crashing.
  2. No `ERROR`/registration exception for `mantle`; the mod appears in the mod list.
  3. Creating a test world loads without crashing.
  4. Exercise Mantle's visible surface: `/mantle …` commands, the book/lectern item (if kept), and a simple
     `BlockEntity`/fluid rendering.
- **Game tests:** if Mantle has `gameTestServer`, wire the NeoGradle run and use it as extra verification
  (non-blocking if absent).

## Section 6 — Risks & deferral policy

- **Unavoidable "big-bang" rewrites:** networking, capabilities, and fluids have cross-dependencies, so some
  moments won't compile partially. Mitigation: stage order 2→3→4 and explicit `// TODO PORT` stubs to isolate.
- **`client/book` + HTML export** (recent commits) is the heaviest/riskiest subsystem and likely **not on
  Tinkers' critical path**. Policy: port normally; if it blocks Stage 6, isolate behind a stub and record as
  debt — do not block "compiles + loads".
- **JEI 1.21.1:** confirm the exact published BlameJared maven version at execution time; if the chosen
  coordinate is missing, adjust to the neighboring stable build. JEI is an **optional** dependency — its
  absence must not break loading.
- **NeoForge 21.1.234 vs 233:** use 234 (confirmed on maven); fall back to 233 if a transitive artifact is
  missing.
- **LopyLuna reference:** use **only** as a pattern reference, never copy blindly — it's an early-stage
  community port (single branch) and may contain incomplete approaches.
- **Honest limit:** "compiles + loads + smoke test" is **not** verified feature parity. Subtle behaviors
  (book rendering, fluid/recipe edge cases) may need a follow-up pass. This is explicitly out of scope for
  this milestone.
- **Next cycle dependency:** on completion, the Mantle 1.21.1 jar / local publish becomes the base the
  Tinkers' Construct port (the next sub-project) builds against.

## Out of scope

- Tinkers' Construct port (separate sub-project, depends on this one).
- Verified feature parity / exhaustive behavior testing of Mantle.
- Forge compatibility (NeoForge-only target, matching the official 1.21.1 direction).
- New features — this is a port, not a redesign.
