# Mantle 1.21.1 / NeoForge Port — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the Mantle library from Minecraft 1.20.1 / Forge 47 to Minecraft 1.21.1 / NeoForge 21.1.234 until it builds (`gradlew build` green) and loads in-game (`runClient` launches, mod registers, smoke test passes).

**Architecture:** Compiler-driven, reference-assisted, staged port on branch `1.21.1`. Migrate the build toolchain to NeoGradle first, then drive the code port by the compiler in dependency order (foundation → networking → content → data → client → integration), then verify at runtime. The compiler is the test harness for stages 0–7; the running client is the test harness for stage 8.

**Tech Stack:** Java 21, NeoForge 21.1.234, NeoGradle 7.0.x (`net.neoforged.gradle.userdev`), Parchment 2024.11.17, Lombok 8.6, JEI 19.21.0.247 (1.21.1/NeoForge, optional).

**Design spec:** [`docs/superpowers/specs/2026-06-27-mantle-1.21.1-neoforge-port-design.md`](../specs/2026-06-27-mantle-1.21.1-neoforge-port-design.md)

## Verification model (read first — this is a port, not greenfield TDD)

There are no meaningful unit tests to write first for an API port. The verification loop is:

- **Per stage (0–7): the compiler is the test.** Each port task ends by running a compile and requiring **zero errors** for the in-scope packages before committing. Command: `./gradlew compileJava` (and `compileTestJava` if a test source set exists).
- **Stage 8: the running client is the test.** `./gradlew runData` then `./gradlew runClient`, plus a manual smoke checklist.
- **Commit after every green step.** Small commits keep the port bisectable.
- **`// TODO PORT` stubs are allowed** only to break cross-package cycles, and only when the same task or a later task removes them. Any stub that survives a stage is listed in that task's commit body.

Run all `gradlew` commands per the **running-windows-scripts** skill (dotnet/Gradle PATH on this Windows machine is via Scoop; if `./gradlew` is not found in Bash, use the PowerShell tool with `.\gradlew.bat`).

## Stage 3 — Networking

### Task 9: Rewrite the network layer over `CustomPacketPayload`

**Files:**
- Modify: `src/main/java/slimeknights/mantle/network/MantleNetwork.java`
- Modify: `src/main/java/slimeknights/mantle/network/NetworkWrapper.java`
- Modify: `src/main/java/slimeknights/mantle/network/packet/*.java`

**API mapping (Forge SimpleChannel → NeoForge payloads):**
- Each packet becomes a `CustomPacketPayload` with a `public static final Type<T> TYPE` and a `public static final StreamCodec<RegistryFriendlyByteBuf, T> STREAM_CODEC`.
- Registration moves from `SimpleChannel.registerMessage(...)` to the `RegisterPayloadHandlersEvent` (mod bus): `registrar.playToClient(TYPE, STREAM_CODEC, handler)` / `playToServer(...)` / `playBidirectional(...)`.
- `ISimplePacket.encode(FriendlyByteBuf)` → the `StreamCodec` carries encode/decode; the handler receives `(payload, IPayloadContext context)` and uses `context.enqueueWork(...)` + `context.player()`.

- [ ] **Step 1: Define the payload pattern (worked example)**

Convert one packet first as the template every other packet follows. Example shape for a packet carrying a `BlockPos`:

```java
public record SwingArmPacket(InteractionHand hand) implements CustomPacketPayload {
    public static final Type<SwingArmPacket> TYPE =
        new Type<>(ResourceLocation.fromNamespaceAndPath(Mantle.modId, "swing_arm"));

    public static final StreamCodec<RegistryFriendlyByteBuf, SwingArmPacket> STREAM_CODEC =
        StreamCodec.composite(
            NeoForgeStreamCodecs.enumCodec(InteractionHand.class), SwingArmPacket::hand,
            SwingArmPacket::new);

    @Override
    public Type<SwingArmPacket> type() {
        return TYPE;
    }

    // former handle(...) body moves here, called from the registrar handler
    public void handle(IPayloadContext context) {
        context.enqueueWork(() -> { /* existing client/server logic */ });
    }
}
```

Use the vanilla `StreamCodec` building blocks: `ByteBufCodecs.VAR_INT`, `BlockPos.STREAM_CODEC`, `ResourceLocation.STREAM_CODEC`, `ByteBufCodecs.STRING_UTF8`, etc., composed via `StreamCodec.composite(...)`.

- [ ] **Step 2: Re-implement `MantleNetwork`/`NetworkWrapper` registration**

Replace the `SimpleChannel` field and `registerMessage` calls with a `register(RegisterPayloadHandlersEvent event)` method:

```java
public void registerPayloads(final RegisterPayloadHandlersEvent event) {
    PayloadRegistrar registrar = event.registrar(Mantle.modId).versioned("1");
    registrar.playToClient(OpenNamedBookPacket.TYPE, OpenNamedBookPacket.STREAM_CODEC,
        (payload, context) -> payload.handle(context));
    registrar.playToServer(SwingArmPacket.TYPE, SwingArmPacket.STREAM_CODEC,
        (payload, context) -> payload.handle(context));
    // ... one line per packet, direction matching the old registerMessage side
}
```

Hook `registerPayloads` onto the mod bus from `Mantle` (restore the `// TODO PORT` listener line from Task 8 if it was stubbed). Keep `NetworkWrapper`'s `sendToServer` / `sendToPlayer` helpers, re-implemented as `PacketDistributor.sendToServer(payload)` / `PacketDistributor.sendToPlayer(player, payload)`.

- [ ] **Step 3: Convert the remaining packets**

Apply the Step 1 pattern to every file under `network/packet/` (`DropLecternBookPacket`, `OpenLecternBookPacket`, `OpenNamedBookPacket`, `UpdateHeldPagePacket`, `UpdateInventoryPagePacket`, `UpdateLecternPagePacket`, and the `ISimplePacket`/`IThreadsafePacket` abstractions — collapse the threadsafe behavior into `context.enqueueWork`).
